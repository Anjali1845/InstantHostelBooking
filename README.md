# 🏨 Instant Hostel Booking System

A Java Swing + MySQL desktop application for managing hostel operations.

## Features

- Student Management (CRUD)
- Room Management (CRUD)
- MySQL Database Integration
- JDBC Connectivity
- Dashboard GUI
- Git Version Control

## Tech Stack

- Java
- Java Swing
- MySQL
- JDBC
- Eclipse IDE
